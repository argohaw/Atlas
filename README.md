## Overview

Atlas is a zero-config Markdown viewer. Drop `.md` files into `public/files/` and they instantly appear in the sidebar — no database, no CMS, no manual config. The file manifest (`files.json`) is auto-generated by a Vite plugin every time you start the dev server or run a build.

---

## Features

| Feature | Details |
|---|---|
| **Instant rendering** | GitHub Flavored Markdown via `react-markdown` + `remark-gfm` |
| **Full-text search** | Searches file titles and body content, results with excerpts, `Ctrl+K` shortcut |
| **Light / Dark mode** | Persisted to `localStorage`, respects system preference on first visit |
| **Responsive layout** | Sticky sidebar on desktop, slide-in drawer on mobile |
| **Syntax highlighting** | 20+ languages via `rehype-highlight`, theme-aware (light/dark) |
| **Auto file discovery** | Vite plugin scans `public/files/` and writes `files.json` automatically |
| **Hot file watching** | Add/remove `.md` files during dev — sidebar updates without restart |
| **Animated UI** | ReactBits-style components: ShinyText, SpotlightCard, AnimatedBorder |
| **Custom logo** | Google-style 4-color geometric "A" (Blue, Red, Gold, Green) |
| **GitHub Pages CI/CD** | One-push deploy via GitHub Actions |

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- npm v9 or higher

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/argohaw/Atlas.git
cd Atlas

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Open [http://localhost:5173/Atlas/](http://localhost:5173/Atlas/) in your browser.

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server with HMR at `localhost:5173` |
| `npm run build` | Type-check + production build to `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run oxlint on the source files |

## Adding Documents

1. Create any `.md` file and place it in `public/files/`:

```
public/files/my-new-doc.md
```

2. That's it. The Vite plugin automatically:
   - Detects the new file
   - Regenerates `public/files/files.json`
   - The sidebar updates instantly (no server restart needed during `npm run dev`)

> **Note:** `files.json` is auto-generated. Do not edit it manually — your changes will be overwritten on the next dev start or build.

## File Ordering

Files are listed in the sidebar in **alphabetical order** by filename. To control the order, prefix filenames with numbers:

```
public/files/
├── 01-introduction.md      → "Introduction"       (first)
├── 02-installation.md      → "Installation"       (second)
├── 03-configuration.md     → "Configuration"      (third)
└── 04-api-reference.md     → "Api Reference"      (fourth)
```

Hyphens and underscores in filenames are converted to spaces, and each word is title-cased automatically.

| Filename | Displayed label |
|---|---|
| `getting-started.md` | Getting Started |
| `01-DSA-Plan.md` | 01 Dsa Plan |
| `api_reference.md` | Api Reference |

## Deployment

Atlas is deployed to GitHub Pages automatically on every push to `main`.

### Automatic (GitHub Actions)

The workflow at `.github/workflows/deploy.yml`:

1. Checks out the code
2. Installs Node 20 + dependencies
3. Runs `npm run build` (which also regenerates `files.json` via the Vite plugin)
4. Deploys the `dist/` folder to the `gh-pages` branch

**First-time setup:**

1. Push your code to GitHub
2. Go to **Settings → Pages**
3. Set **Source** to `Deploy from a branch` → branch: `gh-pages`, folder: `/ (root)`
4. Your site will be live at `https://argohaw.github.io/Atlas/`

### Manual Build

```bash
npm run build
# Output is in dist/ — deploy this folder to any static host
```

Atlas works on any static host: GitHub Pages, Netlify, Vercel, Cloudflare Pages, AWS S3, etc.

> **Note for non-GitHub-Pages hosts:** Update the `base` field in `vite.config.ts` to match your deployment path (use `'/'` for root deployments).

## Configuration

### Changing the base URL

In `vite.config.ts`:

```ts
export default defineConfig({
  base: '/Atlas/',   // Change to '/' for root, or '/your-repo-name/' for GitHub Pages
})
```

### Theme

The color scheme is defined entirely via CSS custom properties in `src/index.css`. Both `[data-theme="dark"]` and `[data-theme="light"]` blocks can be customized independently.

Key tokens:

```css
[data-theme="dark"] {
  --bg-base:       #0a0a0a;
  --text-primary:  #F0EDE6;   /* ivory */
  --gold:          #C9A84C;   /* royal gold */
  --neon-green:    #00F5A0;
  --neon-blue:     #00D9F5;
  --accent-blue:   #1A73E8;   /* Google blue */
}
```

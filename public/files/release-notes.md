# Release Notes

## v1.0.0 — Initial Release

*Released: 2025*

### ✨ New Features

- Full markdown rendering with GitHub Flavored Markdown (GFM)
- Responsive layout: sidebar on desktop, drawer on mobile
- Syntax highlighting for 20+ programming languages
- Automatic file discovery via `files.json` manifest
- Smooth page transitions and hover animations
- Keyboard accessible navigation

### 🐛 Bug Fixes

- N/A — initial release

### 📦 Dependencies

- `react` 18.x
- `react-router-dom` 6.x
- `react-markdown` 9.x
- `remark-gfm` 4.x
- `rehype-highlight` 7.x
